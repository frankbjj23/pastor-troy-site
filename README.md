# Greater Expectation

Greater Expectation is a faith-centered website I created as community service
for Pastor Troy, a good friend and my pastor. The project gives the ministry a
clear, welcoming digital home for its message, visit information, prayer
resources, and Pastor Troy's introduction.

## Project purpose

My goal was to use my web-development skills in service of Pastor Troy, his
wife, and the Greater Expectation congregation. The design follows the
ministry's blue and silver identity while keeping the message and visitor
experience central.

Unconfirmed service times, location details, prayer-request information, and
contact details remain marked as coming soon rather than being guessed.

## Experience

- Responsive presentation for phones and desktop screens
- Direct paths for new visitors, messages, prayer, and Pastor Troy
- Greater Expectation logo and visual identity
- Approved Pastor Troy portrait
- Illustrative ministry scenes used as design elements, not documentary images
- Accessible structure, readable typography, and focused navigation

## Development

```bash
npm install
npm run dev
npm run build
```

The application is built with React and the vinext toolchain. Site code is in
`app/`, and public images are in `public/images/`.
